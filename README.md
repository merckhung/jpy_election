# jpy_election — 日本 2026 第51回衆議院議員総選挙 3D マップ & 選挙ダッシュボード

[日本語](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md)

C++20、Bazel 9（bzlmod）、Vulkan、Skia で構築された、2026年2月8日執行の**第51回衆議院議員総選挙**（および第27回最高裁判所裁判官国民審査）のインタラクティブ 3D 地図とリアルタイム開票ダッシュボードです。

総務省（MIC）の公式確定データに基づく衆議院全465議席（小選挙区289＋比例代表11ブロック176議席）、最高裁国民審査、289小選挙区の全1,119名および比例単独候補を含む全1,284名の候補者情報、432枚の肖像写真、1,931の基礎自治体・分割区ユニットの3Dトポロジーを完全収録しています。

既定言語は**日本語**（`--lang=ja`）で、英語（`--lang=en`）および繁体字中国語（`--lang=zh-TW`）にも完全対応しています。

## 主な機能

- **日本の 3D 地図：**
  - Vulkan と Skia による高パフォーマンスな立体レンダリング（4× MSAA、大気フォグ、海面グリッド）。
  - 全国 47 都道府県、289 小選挙区、1,931 市区町村・分割区ユニットをシームレスにズーム＆ドリルダウン。
  - 沖縄県および小笠原諸島は独立したインセット枠で配置。
- **衆議院選挙制度の完全再現：**
  - 小選挙区（289議席）＋比例代表（11ブロック・176議席）。
  - 重複立候補、惜敗率（sekihairitsu）の自動計算、比例復活当選の自動判定とバッジ表示。
  - ドント方式（D'Hondt method）による各比例ブロックの議席配分計算。
  - 法定得票数（有効投票の10分の1）未満の重複候補の復活権利喪失、名簿登載者不足時の他党繰り上げ再配分アルゴリズムを完全実装。
- **最高裁判所裁判官 国民審査：**
  - 同日執行の国民審査（高須順一裁判官、沖野眞巳裁判官）の罷免可否投票率および信任判定を全国・都道府県別に表示。
- **Skia リアルタイム開票ダッシュボード：**
  - 衆議院 465 議席の過半数（233 議席）および 3 分の 2（310 議席）ラインを明示した半円ヘミサイクルチャート。
  - 各党の獲得議席（小選挙区＋比例代表）、比例得票率、全小選挙区の接戦ランキング（僅差順）。
  - 当選確実（当確）・確定スタンプ、ゼロ打ち速報、比例復活演出。
- **開票シミュレーション & リプレイ：**
  - `--simulate`: 20:00 から 04:00 までの開票夜をリアルタイムまたは倍速（×1〜×4096）で再生。
  - `--replay`: 総務省の公式確定データを時系列に沿って開票夜として再現。
  - `--preelection`: 投票前の候補者届出情報・勢力図カウントダウン。
- **ニュース速報 & 情勢分析 (PiP)：**
  - 日本の主要ニュース（NHK、Yahoo!ニュース、Google ニュース、Japan Times 等）の RSS/Atom フィードを取り込み。
  - キーワードおよび OpenAI 互換 LLM による選挙区・政党・候補者の自動タグ付けと感情分類。
  - 子母画面（PiP）での最新ニュースティッカー表示。
- **BGM 音楽シンセサイザー：**
  - Windows `waveOut`（Linux ALSA）を使用したプログラマティックなアンビエント選挙 BGM（`V` キーでミュート切替）。
- **完全なクロスプラットフォーム & Windows ネイティブ対応：**
  - Windows MSVC (C++20, /utf-8, DirectWrite) に完全対応。
  - GPU がない環境や CI でも、バンドルされた Google SwiftShader CPU Vulkan ドライバ（`--swiftshader`）により完全動作。
  - ヘッドレス描画（`--headless --screenshot=FILE`）による高解像度画像出力。

## ビルドと実行方法

### 動作環境
- **OS**: Windows 10/11 (x64) または Linux (Ubuntu 22.04+)
- **コンパイラ**: MSVC (Visual Studio 2022) または GCC/Clang (C++20 対応)
- **ビルドツール**: Bazel 9 (bzlmod)
- **グラフィックス**: Vulkan 1.2+ 対応 GPU（または内蔵 CPU SwiftShader）

### Windows でのビルドと起動

最も簡単な方法はリポジトリ付属の `run.cmd` を実行することです：

```cmd
# 起動（ビルドが必要な場合は自動でビルドされます。日本語が既定です）
.\run.cmd

# 英語 UI で起動
.\run.cmd --lang=en

# 繁体字中国語 UI で起動
.\run.cmd --lang=zh-TW

# 開票シミュレーション（模擬データ）
.\run.cmd --simulate --sim_clock=21:30

# 公式確定結果の開票夜リプレイ
.\run.cmd --replay --sim_clock=23:00

# 開票前カウントダウン表示
.\run.cmd --preelection

# 特定の選挙区にフォーカスして起動（例：東京1区）
.\run.cmd --focus=13-01

# SwiftShader（CPU 描画）を明示的に指定
.\run.cmd --swiftshader

# ヘッドレスモードでスクリーンショットを書き出し
.\run.cmd --headless --screenshot=screenshot.png
```

Bazel コマンドを直接実行する場合：

```cmd
# アプリケーションのビルド
bazel build //:jpy_election

# テストスイートの実行 (7つの全テスト)
bazel test //tests/...

# 実行
bazel run //:jpy_election
```

### Linux でのビルドと実行

```sh
sudo apt install build-essential libvulkan1 mesa-vulkan-drivers libglfw3-dev \
                 libcurl4-openssl-dev libasound2-dev glslang-tools git

bazel run //:jpy_election
```

## コマンドライン引数

```
使い方: jpy_election [flags]

基本設定:
  --root=DIR            データおよびアセットが配置されているルートディレクトリ（既定: .）
  --results=FILE        監視する開票結果 JSON（既定: data/election/2026/results.json）
  --lang=L              UI 言語: ja（既定, 日本語）, en（English）, zh-TW（繁體中文）
  --focus=CODE          起動時にズームする地域コード（都道府県 13, 選挙区 13-01, 自治体 13101 等）
  --mode=N              カラーモード: 0 小選挙区リード, 1 比例トップ, 2 得票差, 3 投票率, 4 国民審査
  --no_music            BGM 音声を無効化
  --width=W --height=H  ウィンドウ解像度（既定: 1600x900）

シミュレーション & リプレイ:
  --simulate            開票夜のパーティブラインドな模擬データシミュレーションを実行
  --replay              公式確定結果を開票夜として再現
  --preelection         開票前のカウントダウン表示
  --now=YYYY-MM-DDTHH:MM カウントダウン基準日時（JST）の手動指定
  --sim_clock=HH:MM     開票シミュレーション開始時刻（20:00〜04:00 JST）
  --sim_speed=X         シミュレーション倍速（1, 2, 4, ... 4096, 既定: 64）
  --seed=N              シミュレーション乱数シード

ヘッドレス & レコーディング:
  --headless            ウィンドウを表示せずオフライン描画
  --screenshot=FILE     ヘッドレス描画した画像を PNG として書き出して終了
  --record=DIR          指定ディレクトリに連番 PNG フレームを出力
  --record_seconds=S    録画秒数
  --fps=F               録画フレームレート
  --chart_tour=S        録画中に S 秒ごとに地図と各チャートを巡回

ニュース & LLM:
  --news                ニュースフィードの取得・解析を有効化（data/news/feeds.json）
  --news_config=FILE    カスタムフィード設定ファイル
  --mock_news           模擬ニュースの自動生成（--simulate で既定有効）
  --no_llm              LLM を使用せずオフラインのキーワード判定のみで分類
  --llm_base_url=URL    OpenAI 互換エンドポイント（既定: https://api.openai.com/v1）
  --llm_model=NAME      モデル名（既定: gpt-4o-mini）
```

## データエンジニアリングと出典

本プロジェクトのデータパイプラインは `tools/` 配下のスクリプトによって構成されています：

1. **`tools/fetch_raw.py`**:
   - 総務省（MIC）第51回および第50回衆議院議員総選挙確定結果・候補者届出名簿のダウンロード。
   - 西澤明氏（地域・交通データ研究所）「衆議院小選挙区シェープファイル（2022年改定版）」の取得。
   - スマートニュース SMRI 自治体 TopoJSON の取得。
2. **`tools/build_data.py`**:
   - 全 1,892 市区町村および北方領土を 1,931 の基礎自治体・分割区ユニット（全国 289 選挙区）に再構築。
   - 分割自治体（区割改定に伴う分割）を小選挙区ポリゴンで空間クリッピング。
   - 軽量・高精度な `data/map/japan.topo.json`（8,759 アーク）を出力。
3. **`tools/build_election.py`**:
   - 総務省エクセル・PDF 表から全 22 政党、全 1,284 候補者（重複立候補、ふりがな、本名、所属政党、惜敗率）を抽出。
   - `parties.json`, `candidates.json`, `election.json`, `results.json` を生成。
4. **`tools/fetch_photos.py`**:
   - Wikimedia Commons から CC-BY / CC0 / パブリックドメインの候補者肖像写真（432 名分）を自動収集し `assets/photos/` に保存。
